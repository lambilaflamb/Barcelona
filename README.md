# Barcelona Quest 8-Bit — version test
Ouvrir index.html pour tester l'interface. Pour la PWA iPhone, héberger les fichiers sur HTTPS (GitHub Pages), ouvrir dans Safari, puis Partager > Sur l’écran d’accueil.

Inclus : QG/XP, liste de défis, mission secrète, chorizo maudit et minuteurs, drunk meter humoristique, bouton OLÉ, faux CAPTCHA, roue de bars démo, blind test, intru, jeu de Nico, sélection de photo locale, cartes, pouvoir, équipement du marié, kit de survie local, compte à rebours de 48 h.

Limites : démo locale, sans partage entre téléphones, sans connexion/authentification, sans upload de photos et sans notifications push. Les bars sont des exemples fictifs à remplacer par les lieux choisis par les organisateurs. Les défis peuvent être validés localement par le testeur. Ne pas utiliser la jauge comme mesure d'alcoolémie.
