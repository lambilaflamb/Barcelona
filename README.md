# Barcelona Quest 8-Bit — prototype v2

PWA responsive en français, conçue pour iPhone.

## Publication GitHub Pages
1. Décompressez l’archive.
2. Envoyez tous les fichiers à la racine du dépôt GitHub (ou dans le dossier Pages choisi).
3. Dans **Settings → Pages**, sélectionnez la branche et le dossier contenant `index.html`.
4. Attendez le déploiement. Sur iPhone, ouvrez le site dans Safari puis **Partager → Sur l’écran d’accueil**.

## Mode organisateur
PIN de démonstration : **2468**. Ce PIN n'est qu'une barrière d'interface locale, pas une authentification sécurisée.

## Fonctionnalités
- Joueurs, XP, niveaux et journal de quête.
- Défis et mini-jeux, validation par l'organisateur.
- Progression de la tenue du marié, jusqu'au boss final.
- Température de 10 à 40 °C avec réactions contextuelles.
- Chorizo maudit : énigme aléatoire, transfert refusé en cas de mauvaise réponse.
- Gestion locale des joueurs et attribution d'XP.
- Sauvegarde locale et cache PWA.

## Limites
- Les données restent sur un appareil et ne se synchronisent pas entre téléphones.
- Le PIN organisateur n'est pas sécurisé côté serveur.
- Le blind test nécessite de lancer la musique séparément.
- Les questions sur les amis et les indices de chasse au trésor sont à personnaliser.
